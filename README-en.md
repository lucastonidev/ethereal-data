Welcome to the **Ethereal Grimoire** data repository! This space was created specifically to store, translate, and organize Harry Potter universe data in `JSON` format.

## 📖 About the Project

This repository serves as the static database consumed by the main application. The data structured here was inspired by and adapted from the original **PotterApi**. The main goal is to maintain a lightweight, centralized hub for storing information about:

*   🧙‍♂️ **Characters**
*   🏰 **Hogwarts Houses**
*   🪄 **Spells & Curses**
*   📚 **Books**
*   📜 **Quizzes & Tests (like the Sorting Hat and O.W.L.s)**

## 📂 Why JSON?

To ensure the application runs smoothly and doesn't rely on slow requests to complex external databases, structuring the information in `JSON` allows for fast reading, easy maintenance, and multi-language support (such as the `/pt` and `/en` folders in the project structure).
