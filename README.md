Bem-vindo ao repositório de dados do **Ethereal Grimoire**! Este espaço foi criado especificamente para armazenar, traduzir e organizar os dados do universo de Harry Potter em formato `JSON`.

## 📖 Sobre o Projeto

Este repositório serve como a base de dados estática consumida pela aplicação principal. Os dados aqui estruturados foram inspirados e adaptados a partir da base original da **PotterApi**. O objetivo principal é manter um local centralizado e leve para guardar informações sobre:

*   🧙‍♂️ **Personagens**
*   🏰 **Casas de Hogwarts**
*   🪄 **Feitiços e Maldições**
*   📚 **Livros**
*   📜 **Quizzes e Testes (como o Chapéu Seletor e N.O.M.s)**

## 📂 Por que JSON?

Para garantir que a aplicação funcione de maneira fluida e não dependa de requisições lentas a bancos de dados externos complexos, estruturar as informações em `JSON` permite uma leitura rápida, fácil manutenção e suporte a múltiplos idiomas (como as pastas `/pt` e `/en` na estrutura do projeto).

## 🤝 De fã para fã

Este projeto não tem fins lucrativos e foi construído com muito carinho pela comunidade e para a comunidade. O universo de Harry Potter nos inspira, e o Ethereal Grimoire é uma forma de celebrar essa magia através da tecnologia e do desenvolvimento.
